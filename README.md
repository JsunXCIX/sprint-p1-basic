## 1. 프로젝트 제목
- 서울시 1~9호선 관할 역 대상 교통약자 접근성 시설 수준 현황 분석

## 2. 프로젝트 개요
### 배경
- 서울시 내 65세 이상 인구 급증에 따라 지하철 내 교통약자 비중이 지속적으로 상승하고 있음.
- '1역사 1동선'등 인프라 확충 정책이 시행 중이나, 공급 시설과 실제 이용 수요가 일치하지 않는 불균형 사례가 빈번하게 발생하고 있음.
### 목표
- 본 프로젝트는 교통약자의 수요-공급 불일치를 데이터로 실증함.
- 자체 설계한 시설부하지수를 활용해 효율적인 이동권 보장을 위한 최적의 개선 방향과 우선순위를 제시하고자 함.

## 3. 분석 방법론
### 핵심 지표: 시설부하지수 (Weighted Facility Load Index)
- 교통약자의 실질적 이동 편의성을 평가하기 위해 무임승하차 인원과 편의시설 공급량을 결합한 지수를 산출함.

$$시설부하지수 = \frac{\text{무임승하차 인원}}{(EV \times 4) + (ES \times 1)}$$
### 가중치 산정 논리: 엔트로피 분석을 이용한 역가중치 적용
단순 주관적 판단이 아닌, 데이터 분석과 교통약자의 체감 가치를 결합하여 가중치를 확정함.
- 엔트로피 분석 결과: 데이터 변동성 기반 산정 시 'EV(0.2) : ES(0.8)'로 에스컬레이터의 변별력이 높게 나타남.
- 안정적 공급의 역설: 엘리베이터는 정책적 필수 설치로 인해 변동성이 낮으나, 이는 낮은 중요도가 아닌 보편적 복지 자원으로서의 성격을 의미함.
- 최종 결정: 수리적 변동성과 반비례하는 역가중치 원리를 적용. 교통약자에게 대체 불가능한 필수 수단인 EV에 4배의 가중치를 부여하여 체감 편익을 반영함.

| 구분 | 엔트로피 가중치 | 최종 가중치 | 역할 정의 |
| :--- | :---: | :---: | :--- |
| **엘리베이터(EV)** | 0.2021 | **4** | **필수** 이동 수단 (생존권) |
| **에스컬레이터(ES)** | 0.7979 | **1** | **보조** 이동 수단 (편의성) |
